## B. 许可证混用与依赖审查

### [Q-24.B.1] DevHub 主仓的 License 选择  锚定 [Must]

**背景**: DevHub 是开源还是闭源？开源选 MIT / Apache-2.0 / GPL / AGPL / BSL？

**选项**:
- A. **MIT**（最宽松，允许闭源衍生）
- B. **Apache-2.0**（含专利授权 + 显式声明，比 MIT 更稳）
- C. **GPL-3.0**（强 copyleft，衍生必须开源）
- D. **AGPL-3.0**（含网络服务条款，最严）
- E. **BSL 1.1 + 自定义参数**（如 Sentry / CockroachDB，N 年后转 Apache）
- F. **完全闭源**（仅发布安装包，不开源代码）
- G. **闭源源码 + 开源 SDK / Plugin API 部分**（混合）

**推荐默认**: B（Apache-2.0）

**约束**:
- 选 C/D 会导致依赖 Process Hacker 的代码不能商业化
- 选 F 用户无法审计"完全离线"承诺
- 选 G 是 VS Code 模式（核心 MIT，VS Code 品牌闭源）
