## 引言：用户原话的精确解析

用户最新反馈的原话：

> "原本设计的：『打开资源后可以查看**网络拓扑图**和**神经关系图**』的设计消失了，这个设计要在进程、端口、窗口三端都得到应用，作为串联"

这暗含 **3 个事实**：

1. **用户期望两套图**（不是一套）：
  - **网络拓扑图（Network Topology）**：基于真实 OS 级 socket / handle / parent-child 等"硬连接"
  - **神经关系图（Neural Relationship）**：基于因果推断 / 项目归属 / 标签语义等"软连接"

2. **入口位置是"打开资源后"**：意味着附属（点击对象后进入），不是顶级。但 V1-Q-8.H.1 用户又选了"全局一级入口"——所以是**双重存在**。

3. **必须三端贯通**：进程 / 端口 / 窗口三个详情面板都要有这两套图。

**当前源码事实**（来自 Agent B 报告）：
- PortFocusPanel:534 已嵌入 AttachedGraphView（仅一套，混合了拓扑和关系）
- ProcessDetailPanel 没有嵌入图（仅文字列表 line 674-733）— 这是空缺！
- WindowView 关系图入口位置不明
- 全局 TopologyView.tsx 完全实现但 MonitorPanel 4-Tab 中没有入口

**因此 R8 必须**:
- 把"一套图"分裂为两套（网络拓扑 + 神经关系）
- ProcessDetailPanel 补嵌入图
- 全局拓扑暴露一级入口（与附属 + 三端贯通并行）
- 流程图作为第三套（时间序列），R8.A/B 已规划但实现度不明
