### [Q-6.D.2] inject text 的实现方式  锚定 [Must]

**背景**: 用户需求"自动注入"。技术上有几种方案：

**选项**:
- A. **SendInput API**（模拟键盘）
- B. **WM_SETTEXT + WM_KEYDOWN**（直接 message）
- C. **UI Automation API（UIA）**（语义级，找到 input 元素）
- D. **剪贴板模拟**（写剪贴板 + 模拟 Ctrl+V）
- E. **node-pty 直接控制**（仅终端窗口）
- F. **A + C 混合**（默认 SendInput，UIA 作语义校验）

**推荐默认**: F + E（终端用 pty，GUI 用 SendInput + UIA）

**影响范围**: F 需 koffi 或 nodejs-win32 FFI；E 需 node-pty。

**用户回答**: _________F + E（终端用 pty，GUI 用 SendInput + UIA） 参照市面上的AI CLI的inject___最佳实践，如果最佳实践和目前内容有冲突，作出深刻判断后抉择____________
