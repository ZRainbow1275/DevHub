# 01 — 元层 / 愿景决策（提炼版）

> **派生自**: `prompts/0503/01-meta-vision-survey.md`
> **目的**: 锁定 DevHub 的产品定位、目标用户、设备假设、性能预算、保留期，为后续 PRD/Spec 提供宪法级输入。

---

## A. 产品定位（[Q-1.A.1] [CHANGE→EXTEND]）

**用户回答**: A + B + C + D（全选）

四元定位同时成立：
- **A. 个人开发助手**（首选场景）
- **B. 团队透明度工具**（多人共用 / 跨工位巡查）
- **C. AI 工具编排平台**（Codex / Claude / Gemini 协调）
- **D. 系统监控面板**（Process Explorer 风）

**PRD 影响**:
- IA 必须支持"模块按角色显隐"（个人 vs 团队 vs 编排者）
- 每个面板都需要"私域模式" / "演示模式"切换
- 不允许出现"小众分支被砍"的设计

## B. 发布策略（[Q-1.A.2] [ACCEPT]）

**用户回答**: C — 公开发布 / 公司外部用户

**PRD 影响**:
- 必须签名（10.B.1 = B 自签）
- 文档语言：简中为主（用户使用简体中文）
- 不收集遥测（09.H.1）
- UI 必须考虑非内部用户的引导（08.A.4 D — 首次 Tour）

## C. 用户运行强度（[Q-1.B.1] [ACCEPT]）

**用户回答**: D — 长时间运行（24/7）

**PRD 影响**:
- 性能预算严格（见 D 节）
- 必须自检泄漏 / 死锁 / 句柄堆积
- Watchdog 自身有 self-watchdog（07.J.2）
- 内存上涨触发 → 告警 + 询问后重启（09.J.2）

## D. AI 任务规模（[Q-1.B.2] [ACCEPT]）

**用户回答**: D — 超长任务（含 8h+ 巡航）

**PRD 影响**:
- AI 任务状态机三层（07.B.4 C：idle/active/long-running/critical）
- CSV 任务驱动必须支持中断 + 续跑（07.E.4 D）
- 进度计算需要"长任务专属逻辑"（07.A.4 D）

---

## E. 同时运行 AI 实例数（[Q-1.D.4] [ACCEPT]）

**用户回答**: D — 极端 >10

**PRD 影响**:

- 列表/卡片必须支持虚拟化滚动（10.D 默认 react-window）
- 关系图必须支持 500+ 节点（08.G.1 D 自适应）

## F. 设备分辨率覆盖（[Q-1.C.1] [EXTEND]）

**用户回答**: 全选

支持矩阵：

**PRD 影响**:

## G. 性能预算（[Q-1.E] [ACCEPT]）

| 维度 | 预算 |
|------|------|
| 主进程 RSS | < 400 MB |
| 渲染进程 RSS | < 1 GB（含 AI 关系图） |
| 主进程 CPU | < 5%（空闲） |
| 渲染进程 CPU | < 15%（活跃） |
| 24h 内存增长 | < 10%（基线） |
| 子进程总数 | < 10 |

**PRD 影响**:
- 限流 token bucket（09.B.1 C）
- IPC RPM 限制（09.B.3 默认表）
- 超出 → 状态栏红条 + 自动诊断（09.D.3）

---

## H. 数据保留（[Q-1.F] [ACCEPT]）

| 类型 | 保留期 |
|------|--------|
| 进程/端口/窗口扫描 | B — 1 小时 |
| AI 任务历史 | D + E — 30 天热 + 90 天冷归档 |
| 任务录像（轻量） | B + 可选 C — 默认开启 |
| 审计日志 | C — 30 天 |
| 崩溃报告 | B — 仅本地保存 |

**PRD 影响**:
- 数据库需要分级冷热存储
- 用户可手动导出（09.J.1 是 — 诊断包导出）

## J. 关键 PRD 信号

1. **"全民通吃"** — 不锁定任何人群
2. **永续运行** — 设计哲学，每个模块都要回答"24h 后会怎样"
3. **超长 AI 任务** — 信号融合 + 状态机不可妥协
4. **隐私 + 本地** — 公开发布但零遥测，矛盾点用本地诊断包替代
5. **响应式覆盖** — 4 断点 + 小屏收纳
