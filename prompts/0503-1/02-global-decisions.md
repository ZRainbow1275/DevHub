> **派生自**: `prompts/0503/02-global-experience-survey.md`
> **核心痛点**: "整体显示太不均匀，需多种收纳"
> **设计哲学**: 三栏不动 + 收纳系统冗余 + 命令面板补强

---

## D. 收纳系统（[Q-2.B] 全节 [EXTEND]）

### D.1 收纳机制（[Q-2.B.3] [EXTEND]）
**用户回答**: A + B + C + D + F（不要 E 浮动子工具栏）

支持的收纳形式：
- **A. 顶部下拉抽屉**（搜索 / 通知 / 任务队列）
- **B. 右侧滑出抽屉**（详情面板）
- **C. 底部抽屉**（日志 / 终端 / 调试）
- **D. 浮动悬浮卡片**（hover/click 触发）
- **F. 状态栏聚合**（底部）
- 不要 E（浮动子工具栏）

### D.2 浮卡 vs 抽屉的边界（[Q-2.B.4] [ACCEPT]）
**用户回答**: D — Pop-out 混合（默认渲染层 + 升级 BrowserWindow）

### D.3 命令面板（[Q-2.E] [EXTEND]）

- 跳转

- 历史记忆

### D.4 键位预设（[Q-2.F] [ACCEPT]）

## H. 可访问性（A11y）（[Q-2.J]）

**用户回答**: 全选（A + B + C + D + E + F + G + H + J）

---

## I. PRD 信号

1. **三栏不动**：所有改进都基于现有三栏，不动 IA 主结构
2. **收纳冗余**：5 种机制并存（顶/右/底/浮/聚合），用户偏好驱动
3. **命令面板**：是冗余但不可少，作为"低成本加速器"
4. **密度独立**：模块级密度可覆盖全局
5. **响应式 4 断点**：所有组件设计必须考虑 < 1280px 行为
6. **A11y 全套**：减弱动效、屏幕阅读器、色盲友好、键盘可达必须实现
