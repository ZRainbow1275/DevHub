## B. 悬浮卡片（Pop-out）系统

### B.1 触发方式（[Q-5.B.1] [CHANGE→EXTEND]）
**用户回答**: **A + B + C + D**（默认是 A+B+D，**用户加入 C 拖拽**）

## C. 端口字段

### C.1 卡片字段（[Q-5.C.1] [ACCEPT]）
**用户回答**: 全选

必有 + 可选字段全部展示：
- 端口号 / 协议 / 状态 / 占用 PID / 进程名 / 标签
- 远端地址 / 远端端口 / 本地接口 / 监听用户 / 启动时间

### C.2 详情扩展字段（[Q-5.C.2] [EXTEND]）
**用户回答**: 「全选，**危险内容走用户授权**」

**关键约束**: HTTP 嗅探必须显式 opt-in（默认关闭），且每次启动嗅探都需当面同意

## D. 安全分级

### D.1 等级方案（[Q-5.D.1] [ACCEPT]）
**用户回答**: A — 接受默认 4 档

| 等级 | 含义 | 视觉 |
|------|------|------|
| Local | 仅 127.0.0.1 / ::1 | 绿色徽章 + ShieldCheckIcon |
| LAN | 192.168.x / 10.x / 172.16-31.x | 黄色徽章 + ShieldIcon |
| WAN-Capable | 0.0.0.0 / :: | 橙色徽章 + ShieldAlertIcon |
| Suspicious | 黑名单端口 / 异常远端 | 红色徽章 + ShieldXIcon |

> **不使用 Emoji 色块**，全部走 lucide-react 图标 + 颜色 token

- 用户可在设置面板增删
- 黑名单触发 → Suspicious 标识 + 通知

### D.3 安全提示位置（[Q-5.D.3] [EXTEND]）

## K. PRD 信号

1. **Pop-out 系统是 R8.B 重头戏**：5 种触发方式，用户加了拖拽
2. **真实 BrowserWindow 升级路径**：浮卡可摘到第二屏
3. **HTTP 嗅探隐私优先**：默认关闭，每次启动都问
4. **冲突识别"潜在意图"**：不只是同端口多 PID
5. **释放/冲突优先**：用户最在意的两件事
6. **全部端口绑定/释放都通知**：用户需要全量感知（后期可调）
7. **黑名单可扩展**：内置 30 + 用户补充
