## 一、三症状一组

### 1.1 无滚动
截图 `屏幕截图 2026-04-15 195159.png`：端口监控页展示 128 活跃端口、55 监听、68 已连接、0 冲突，并列出了 12 个常用端口 + 若干端口卡片，但滚动条缺失，下方内容无法检视。

### 1.2 布局挤压
截图 `屏幕截图 2026-04-15 195211.png`：左侧三列端口卡片（:135 / :445 / :902）被严重压窄，右侧一个 PortFocusPanel 占了 ~60% 宽度，整个主区下方的"本地地址"字段溢出。

### 1.3 查询超时
同截图右侧 PortFocusPanel 顶部有黄色警告条 `⚠️ 查询超时 - 显示缓存数据`。

## 二、根因假设

### 滚动
- 端口 Tab 外层容器没有 `overflow-y: auto` 或固定高度
- 或嵌套组件继承了 `overflow: hidden`

### 布局挤压
- PortFocusPanel 用了固定 `width: 640px` / 百分比且无最小宽度保护
- 端口卡片网格 `grid-template-columns` 用了 `auto-fill, minmax(200px, 1fr)`，但 minmax 值不符合卡片内容最小宽度

### 查询超时
- R5 已暴露 PowerShell CIM 爆炸，端口扫描（netstat + process mapping）可能也受牵连
- 超时处理显示缓存数据是合理降级，但"总是超时"就不对了

## 三、验收契约

- [ ] 端口 Tab 支持滚动，可见所有端口卡片
- [ ] PortFocusPanel 打开时，主列表区最小宽度 480px，不被压窄到卡片溢出
- [ ] PortFocusPanel 可关闭/拖拽缩放
- [ ] "查询超时"出现率 ≤ 5%（如果高于此，先修 P2.1 Runtime 再来）
- [ ] 首次查询超时时：
  - 显示缓存数据 + 指示"重试中"
  - 自动重试 1 次（带更长超时 + 低优先级）
  - 第二次失败才显示持久错误
