# Code of Conduct

## Standard

DevHub contributors are expected to keep discussions technical, respectful, evidence-based, and focused on improving the project.

## Unacceptable Behavior

- Harassment or discriminatory language
- Publishing private security details before coordinated disclosure
- Sharing another user's logs, screenshots, diagnostic packs, or secrets without permission
- Repeated off-topic disruption
- Personal attacks in code review or issue discussion

## Enforcement

Maintainers may edit issue titles for clarity, ask for reproduction evidence, hide comments that expose secrets, lock threads that become unproductive, or restrict participation after repeated violations.

## Reporting

For conduct issues, contact the repository maintainers. For security issues, use SECURITY.md instead of a public thread.
