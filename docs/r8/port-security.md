# R8.B Spec-13 Port Security Tier Banner

## Scope

This slice implements the real port security path required by `prompts/0503-2/R8.B/spec-13-port-security-tier-banner.md` without mock data:

- Shared classifier in `src/shared/port-security.ts`.
- Zod source-of-truth schemas in `src/shared/schemas/r8-runtime.ts`.
- Main-process persistence and IPC through `R8RuntimeService` and `r8RuntimeHandlers`.
- Renderer banner, tier badges, and blocklist editor over the existing port scanner data.
- Statusbar `public-ports` tile now counts only `WAN-Capable` ports and reports suspicious count in the tooltip.

## Tier Contract

| Tier | Bind condition | Visual tone | Notes |
|---|---|---|---|
| `Local` | `localhost`, `127.0.0.0/8`, `::1` | success | No network-facing listener. |
| `LAN` | RFC1918 IPv4, IPv4 link-local, IPv6 unique/local-link | warning | Private network exposure. |
| `WAN-Capable` | wildcard bind or public/non-private bind | orange | Potentially reachable outside the machine or LAN boundary. |
| `Suspicious` | default suspicious port or user blocklist match | error | Takes precedence over address classification. |

## Blocklist Behavior

- Default suspicious ports are generated by code and are not stored as mutable user data.
- User entries persist in the existing `devhub-r8-runtime` electron-store under `blocklist`.
- User entries are capped at `500` and validated to a port range of `1..65535`.
- Corrupted stored user entries are discarded and the cleaned list is persisted.
- Reset clears only user entries; default entries remain available through the generated list.

## IPC

| Channel | Purpose |
|---|---|
| `port:security-tier` | Classifies one real port/address pair. |
| `port:blocklist-list` | Returns default and user entries. |
| `port:blocklist-add` | Adds or updates one user entry. |
| `port:blocklist-remove` | Removes user entries by id, port, or IP. |
| `port:blocklist-reset` | Clears user entries and returns defaults. |
| `port:public-banner-state` | Counts `WAN-Capable` and `Suspicious` ports from scanner cache or supplied rows. |

## Renderer Surfaces

- `PublicPortBanner` renders only when the current real port list contains at least one `WAN-Capable` or `Suspicious` port.
- `SecurityTierBadge` is shown in port cards, port list rows, and `PortFocusPanel`.
- `BlocklistEditor` is mounted under Settings -> Advanced -> Port Security and uses the real preload bridge.
- The port monitor now has an `exposed` filter for `WAN-Capable` and `Suspicious` ports.

## Boundary

This slice does not claim Electron Playwright persistence E2E or OS firewall verification. It does provide executable service contracts, IPC validation, renderer integration, settings UI, and low-resource targeted tests.
