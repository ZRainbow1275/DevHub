# R8.B spec-15 i18n Scaffold

## Implementation Status

This slice installs and wires a real i18next scaffold while keeping Simplified Chinese as the default product language.

- Source spec: `prompts/0503-2/R8.B/spec-15-i18n-scaffold.md`
- Feature flag: `R8.B.i18n.scaffold`
- Default locale: `zh-CN`
- Preview locale: `en-US`
- Status: verified scaffold with legacy production-text coverage, packaged Electron E2E, and `t()` benchmark evidence

## Dependencies

- `i18next`
- `react-i18next`

Both dependencies are installed in `devhub/package.json` and locked through `pnpm-lock.yaml`.

## Contracts

Locale contracts live in `src/shared/schemas/r8-runtime.ts`:

- `Locale`
- `LocaleManifest`
- `LocaleGetResponse`
- `LocaleSetRequest`
- `LocaleSetResponse`
- `LocaleListResponse`
- `LocaleReloadResponse`

The supported locale set is intentionally small: `zh-CN` and `en-US`.

## Main Process

- `src/main/services/LocaleStore.ts`
  - Persists locale in `electron-store` under `devhub-locale`.
  - Defaults invalid or missing values to `zh-CN`.
  - Returns locale manifests without emoji flags.

- `src/main/ipc/i18nHandlers.ts`
  - `i18n:get-locale`
  - `i18n:set-locale`
  - `i18n:list-locales`
  - `i18n:reload-resources`

- `src/main/ipc/index.ts`
  - Registers `R8RuntimeService` before concrete extended handlers, then registers i18n after R8 cleanup so `i18n:*` never falls back to `E_R8_CONTRACT_ONLY` in the packaged runtime.
  - Keeps scoped topology setup idempotent so contract-only fallback handlers cannot interrupt later concrete handler registration.

## Renderer

- `src/renderer/i18n/index.ts`
  - Initializes i18next with `react-i18next`.
  - Uses `zh-CN` fallback.
  - Renders `[missing.key]` in dev-compatible missing-key mode.

- `src/renderer/i18n/zh-CN.json`
  - Provides the zh-CN resource namespace set for common, settings locale, cmdk, monitor, errors, and a generated `legacy` catalog.
  - The `legacy` catalog covers 1169 unique production renderer Chinese strings from the current source tree.
  - Current bundle size is 50.83KB, below the 80KB budget.

- `src/renderer/i18n/en-US.json`
  - Provides matching partial English coverage for settings, command placeholder, monitor tab labels, and errors.

- `src/renderer/components/i18n/LocaleProvider.tsx`
  - Wraps the React app.
  - Loads persisted locale through preload.
  - Applies `document.documentElement.lang` without restart.
  - Installs the legacy DOM localizer so historical components are routed through `i18n.t(legacy.<hash>, { defaultValue })` without a high-risk source-wide rewrite.

- `src/renderer/i18n/legacy-dom-localizer.ts`
  - Translates legacy text nodes plus `aria-label`, `aria-description`, `title`, and `placeholder` display attributes.
  - Preserves original text so switching back to `zh-CN` is deterministic.
  - Prevents missing legacy keys from leaking as `legacy.<hash>` and stops managing nodes once React/i18next replaces them with non-Chinese translated text.
  - Does not mutate form values or scanner data.

- `src/renderer/components/i18n/LocaleSwitcher.tsx`
  - Exposes runtime language switching in Settings -> Advanced -> Language and Region.

- `src/renderer/hooks/useT.ts`
  - Provides a typed translation hook over the default zh-CN key tree.
  - Caches resolved translations by active locale, key, and fallback so repeated renderer `t()` calls remain under the spec performance budget.

## Scripts

- `pnpm -C devhub i18n:extract`
  - Scans `src/renderer` for hardcoded Chinese string literals.
  - Separates production findings from test findings.
  - Reports `uncoveredLegacyStrings` for strings not covered by `zh-CN.legacy`.

- `pnpm -C devhub i18n:check`
  - Checks zh-CN bundle size and key coverage.
  - Checks en-US partial coverage threshold.
  - Checks 100% production legacy catalog coverage.
  - Runs in both Windows and Linux CI jobs before unit tests.

- `pnpm -C devhub bench:i18n`
  - Runs `scripts/bench-i18n-t.mjs` against real zh-CN/en-US resources and the DevHub cached translation path.
  - Enforces 10,000 `t()` calls under 50ms and locale switching under 200ms.
