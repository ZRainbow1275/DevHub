# Terms of Use

These terms describe expected use of DevHub project builds and documentation.

## Acceptable Use

Use DevHub only on machines, projects, AI tools, accounts, and windows that you are authorized to inspect or control.

Do not use DevHub to:

- Access another user's local data without permission
- Exfiltrate secrets or diagnostic artifacts
- Evade security controls
- Misrepresent third-party affiliation
- Remove license or attribution notices

## Local-First Operation

R8 features are designed to keep telemetry, diagnostics, OCR, and cloud sync disabled unless a future release explicitly implements and documents those capabilities.

## Project Materials

Documentation, screenshots, issue templates, and examples are provided for project governance and user education. The AGPL-3.0 license controls source code rights.
